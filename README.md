# Una pregunta para ti

Una página romántica en español hecha con HTML, CSS y JavaScript, sin dependencias.

## Abrir

Abre `index.html` en cualquier navegador moderno. No requiere instalación ni servidor.

Al elegir “Sí, muchísimo” aparece una carta y un marco de foto estáticos, preparados para añadir su contenido directamente en `index.html`.
